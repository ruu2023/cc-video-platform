# 動画講座プラットフォーム

## 概要
クリエイター本人が制作した動画講座（コース）を、買い切り形式で販売するプラットフォーム。視聴者はコースを一度購入すれば無期限にストリーミング視聴でき、講座・ハウツー系コンテンツに特化する。単一クリエイターの直販に絞ることで、マーケットプレイス的な複雑さを持たずシンプルに運用できる。

## ターゲットユーザー

### クリエイター（運営者本人）
- 自分の専門知識・スキルを動画講座としてまとめ、直販したい個人。
- 管理画面からコースやチャプター動画を自分で登録・管理する。

### 視聴者（購入者）
- 特定分野の講座・ハウツーを学びたい個人。
- アカウントを作成し、気に入ったコースを買い切りで購入して繰り返し視聴する。

## 機能一覧

### コース・コンテンツ
- コース一覧・詳細ページ（説明文・サムネイル表示）: 高
- コースは複数チャプター（動画）で構成される: 高
- 購入前は説明文・サムネイルのみ閲覧可能（無料プレビューなし）: 高
- チャプターごとの付属資料（PDF・ソースコード等）ダウンロード: 中

### 購入・決済
- コース単位の買い切り購入（Stripe Checkout）: 高
- 購入後は無期限で視聴可能: 高
- 個別動画の単品購入・クーポン割引: なし（スコープ外）

### アカウント・認証
- 視聴者はアカウント登録必須（購入前に作成）: 高
- ログイン状態に応じた購入済みコースの表示: 高

### 視聴体験
- 購入者限定のストリーミング再生（トークン認証で保護、ダウンロード不可）: 高
- 視聴進捗の保存（続きから再生）: 中
- チャプターごとの視聴完了チェック: 中

### 管理機能（クリエイター向け）
- 管理画面ログイン: 高
- コースの作成・編集: 高
- チャプター（動画）の登録、bunny.net アップロード動画との紐付け: 高
- 付属資料ファイルの登録: 中

## スコープ外（今回のバージョンでは扱わない）
- マーケットプレイス化・複数クリエイター対応
- サブスクリプション課金
- クーポン・割引コード
- 自動返金機能（返金は運営が手動対応）
- メール通知（購入完了メール等。画面表示のみで完結させる）
- DRM・画面録画対策・動画への透かし

## 技術スタック推奨
- フロントエンド/バックエンド: Next.js
- データベース: Turso
- 動画ストレージ・配信: bunny.net（トークン認証によるストリーミング保護を利用）
- 決済: Stripe（Stripe Checkout）
- 認証: better-auth
