## Sprint 3: コース購入フロー（Stripe Checkout）

### 実装する機能
- 機能A: コース詳細ページからの購入導線（購入ボタン、未ログイン時はログイン/登録へ誘導）
- 機能B: Stripe Checkout によるコース単位の単発課金
- 機能C: 決済完了後の購入済み状態の反映（マイページ・コース詳細ページ）

### スプリント契約（完了条件）
以下の全条件を満たした場合のみ、このスプリントは完了とする。

- [ ] 未ログイン状態でコース詳細ページの購入ボタンを押すと、ログインまたは新規登録画面に誘導される
- [ ] ログイン済みユーザーがコース詳細ページの購入ボタンを押すと、Stripe Checkout の決済画面に遷移する
- [ ] Stripe Checkout でテスト用カード情報を使って決済を完了できる
- [ ] 決済完了後、アプリに戻ると購入完了が画面上に表示される（メール通知は行わない）
- [ ] 決済完了後、そのコースが「購入済みコース一覧（マイページ）」に表示される
- [ ] 購入済みのコースの詳細ページでは、購入ボタンではなく「視聴する」等の導線に切り替わる
- [ ] 同じコースを既に購入済みのユーザーが再度コース詳細ページを開いても、二重購入を促す購入ボタンは表示されない
- [ ] 決済をキャンセルした場合、購入は成立せず、購入済みコース一覧にも表示されない
- [ ] 購入記録（ユーザー・コース・購入日時）がデータベースに保存される
