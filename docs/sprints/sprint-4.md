## Sprint 4: 動画視聴プレイヤーと進捗管理

### 実装する機能
- 機能A: 購入者限定の動画ストリーミング再生（bunny.net トークン認証で保護）
- 機能B: チャプターの視聴進捗保存・続きから再生
- 機能C: チャプターごとの視聴完了チェック表示

### スプリント契約（完了条件）
以下の全条件を満たした場合のみ、このスプリントは完了とする。

- [ ] 購入済みユーザーがコース詳細ページからチャプターを選ぶと、動画が再生される
- [ ] 未購入ユーザーが同じチャプターの再生URLに直接アクセスしても、動画は再生できない
- [ ] ログインしていないユーザーが再生URLに直接アクセスしても、動画は再生できない
- [ ] 動画の再生用URL/トークンには有効期限があり、期限切れ後は再生できない
- [ ] 動画再生ページに動画のダウンロードボタンやダウンロード可能なリンクが存在しない
- [ ] 視聴中に再生を中断し、再度同じチャプターを開くと、前回の再生位置から再開できる
- [ ] チャプターを最後まで視聴すると、そのチャプターが「視聴完了」としてマークされる
- [ ] コース詳細ページ（購入後）で、各チャプターの視聴完了状況（完了/未完了）が一覧表示される
- [ ] 全チャプターを視聴完了すると、コース全体の進捗が100%として表示される
