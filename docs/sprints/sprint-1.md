## Sprint 1: アカウント基盤とコース一覧・詳細ページ

### 実装する機能
- 機能A: 視聴者向けアカウント登録・ログイン・ログアウト（better-auth）
- 機能B: コース一覧ページ（公開されているコースをカード表示）
- 機能C: コース詳細ページ（説明文・サムネイル・チャプター一覧のタイトルのみ表示、動画本体は未再生）

### スプリント契約（完了条件）
以下の全条件を満たした場合のみ、このスプリントは完了とする。

- [ ] メールアドレスとパスワードで新規アカウントを作成できる
- [ ] 作成したアカウントでログインできる
- [ ] ログイン中のユーザーがログアウトできる
- [ ] 未ログイン状態でコース一覧ページにアクセスすると、コースのタイトル・サムネイル・価格が一覧表示される
- [ ] コース一覧のカードをクリックすると、そのコースの詳細ページに遷移する
- [ ] コース詳細ページに説明文・サムネイル・チャプタータイトル一覧が表示される
- [ ] コース詳細ページでは動画は再生できず、チャプターのタイトルのみが表示される（本文・サムネイル以外のプレビューは提供しない）
- [ ] 未ログイン状態でコース詳細ページを開いても閲覧はできる（説明文・サムネイルのみのため購入導線は表示されるがログインを強制しない）
- [ ] ログイン中はヘッダー等に自分のログイン状態（メールアドレス等）が表示される
- [ ] 存在しないコースIDにアクセスすると404相当の表示になる
