## Sprint 2: 管理画面によるコース・チャプター管理

### 実装する機能
- 機能A: クリエイター用管理画面ログイン（一般視聴者と区別されたアクセス制御）
- 機能B: コースの作成・編集・公開/非公開切り替え
- 機能C: チャプター（動画）の追加・編集・並べ替え、bunny.net にアップロード済みの動画との紐付け
- 機能D: チャプターへの付属資料ファイルの登録

### スプリント契約（完了条件）
以下の全条件を満たした場合のみ、このスプリントは完了とする。

- [ ] クリエイターアカウントでログインすると管理画面にアクセスできる
- [ ] 一般の視聴者アカウントでログインした場合、管理画面にアクセスできない（アクセス拒否またはリダイレクトされる）
- [ ] 管理画面から新しいコース（タイトル・説明文・サムネイル・価格）を作成できる
- [ ] 作成したコースを編集し、変更内容が保存される
- [ ] コースを「公開」「非公開」に切り替えられ、非公開のコースは一般のコース一覧に表示されない
- [ ] コースにチャプター（タイトル・bunny.net の動画ID/URL）を追加できる
- [ ] 追加したチャプターの順序をドラッグ＆ドロップまたは操作で並べ替えられる
- [ ] チャプターを削除できる
- [ ] チャプターに付属資料ファイル（PDF等）をアップロード・紐付けできる
- [ ] 管理画面で登録したコース・チャプターの内容が、視聴者向けのコース一覧・詳細ページに反映される
