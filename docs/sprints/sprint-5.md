## Sprint 5: 付属資料ダウンロード

### 実装する機能
- 機能A: 購入者限定の付属資料（PDF・ソースコード等）ダウンロード
- 機能B: チャプター視聴画面・コース詳細画面からの資料アクセス導線

### スプリント契約（完了条件）
以下の全条件を満たした場合のみ、このスプリントは完了とする。

- [ ] 購入済みユーザーが、資料が登録されているチャプターの視聴画面から資料をダウンロードできる
- [ ] ダウンロードしたファイルが管理画面でアップロードした内容と一致する
- [ ] 資料が登録されていないチャプターには、ダウンロードボタンが表示されない
- [ ] 未購入ユーザーが資料のダウンロードURLに直接アクセスしても、ダウンロードできない
- [ ] ログインしていないユーザーが資料のダウンロードURLに直接アクセスしても、ダウンロードできない
- [ ] 1つのチャプターに複数の資料が登録されている場合、すべての資料が個別にダウンロードできる
- [ ] コース詳細ページ（購入後）から、コース内の資料一覧をまとめて確認できる
