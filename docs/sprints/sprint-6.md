## Sprint 6: Bunny.net 本番切替（署名付き再生URL・Storageサムネイル・既存動画紐付け・動画アップロード）

### 実装する機能
- 機能A: 署名付き再生URLの Bunny Stream 本番方式への切替（`HS256-` プレフィックス + base64url(HMAC-SHA256) 形式の token と expires クエリを発行。現行の独自署名方式からの修正を含む）
- 機能B: サムネイルの Bunny Storage 保存と Pull Zone（CDN）経由配信（Storage Zone への保存はシンガポールリージョンAPI `https://sg.storage.bunnycdn.com/{zone}/{path}` を使用）
- 機能C: Bunny Stream にアップロード済みの既存動画（エンコード済み・検証済みの `a0058ffd-91ce-46b0-a39e-c593be7f9a52`）のチャプターへの紐付けと本番配信
- 機能D: チャプター編集画面からの動画アップロード（creator権限のみ。アプリ内サーバー側API経由で Bunny Stream へ作成→アップロード→エンコード完了待ち→GUID をチャプターに保存。`BUNNY_STREAM_API_KEY` はブラウザに露出させない）

### スプリント契約（完了条件）
以下の全条件を満たした場合のみ、このスプリントは完了とする。

#### 署名付き再生URL（機能A）

- [ ] 購入済みユーザーが視聴ページを開いたとき、動画プレイヤーが読み込むURLが `BUNNY_STREAM_HOSTNAME`（vz-30955aeb-983.b-cdn.net）配下であり、`token` と `expires` の2つのクエリパラメータを含む
- [ ] 発行される token が `HS256-` プレフィックス付きの base64url 文字列になっており、署名計算に `BUNNY_STREAM_TOKEN_KEY` の生値と `path + expires` が使われている（現行の subject 結合・プレフィックスなし方式は残っていない）
- [ ] 視聴ページで発行された署名付き再生URLにそのままアクセスすると、HTTP 200 が返る。また token の一部を改変したURL、または expires を過去時刻に書き換えたURLでアクセスすると、動画は取得できない（403 等）
- [ ] 購入済みユーザーが視聴ページで動画をシーク操作込みで途切れず再生でき、再生中の HLS セグメント（.ts / .m3u8）や MP4 フォールバックのリクエストが 403 等で失敗しないこと（ディレクトリ署名・MP4 フォールバックのいずれの方式でもよいが、playlist の相対セグメントに token が引き継がれず失敗する状態は不可。検証は機能Dでアップロードした長めの動画、または既存動画の全長再生とループ再生で行ってよい）

#### サムネイルの Storage 保存・CDN 配信（機能B）

- [ ] 管理画面でコースのサムネイルを登録・更新すると、ファイルが Storage Zone（video-plat-form-sub-ruu）内に保存される。書き込みは `https://sg.storage.bunnycdn.com/{zone}/{path}` に対して、認証ヘッダーに `BUNNY_STORAGE_KEY` を使って行われる（日本リージョン既定ホストへの誤送信がない）
- [ ] コース一覧ページとコース詳細ページで表示されるサムネイル画像の取得元が `BUNNY_ASSETS_HOSTNAME`（video-ruu-zone.b-cdn.net）配下のURLになっており、そのURLにアクセスすると HTTP 200 が返って画像が壊れずに表示される

#### 既存動画の紐付け（機能C）

- [ ] 管理画面でチャプターに Bunny Stream の動画ID（`a0058ffd-91ce-46b0-a39e-c593be7f9a52`）を紐付けると、その動画のサムネイル・タイトル情報がチャプターに反映され、購入済みユーザーが視聴ページで（機能A の署名付きURL経由で）再生できる

#### チャプター編集画面からの動画アップロード（機能D）

- [ ] creator権限のユーザーがチャプター編集画面で動画ファイルを選択してアップロードすると、エンコード完了後にその動画が自動的にチャプターに紐付けられ、購入済みユーザーが視聴ページで再生できる
- [ ] アップロード中およびエンコード中は「エンコード中」等の進捗状態が画面に表示され、エンコード完了（Bunny Stream の status=4）後に「完了」へ切り替わる
- [ ] アップロード処理がアプリ内のサーバー側API経由で行われ、ブラウザから発行されるどのリクエスト（リクエストヘッダー・ボディ・ページソース）にも `BUNNY_STREAM_API_KEY` の値が含まれていない
- [ ] viewer権限のユーザーにはチャプター編集画面にアップロードUIが表示されず、アップロード用APIに直接リクエストしても拒否される（403 等）

#### 既存機能の回帰保護

- [ ] 未購入ユーザーおよび未ログインユーザーが、署名付きURLの発行経路を通らず動画へ直接アクセスしても、動画は再生できない（Sprint 4 のアクセス保護が維持されている）
- [ ] コース一覧・コース詳細・購入フロー（Stripe Checkout）・ログイン/ログアウト・資料ダウンロード（Sprint 1〜5 の機能）が、切替後も従来どおり動作する
